# Security Policy

## Supported Versions

ComputeEdge is an active research project. Security fixes are applied to the latest revision of the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability or security-sensitive defect in ComputeEdge, please disclose it responsibly.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send a detailed report via email to:
- **Contact:** `bibek198c@gmail.com`

### What to Include

Please provide:
1. A description of the vulnerability and its potential impact.
2. Steps to reproduce the issue or a minimal reproducible proof-of-concept.
3. The affected environment details (macOS version, hardware model, compiler).
4. Any potential mitigations or fixes if identified.

### Response Process

- You will receive an acknowledgment of your report within 48 hours.
- A status update will be provided once the issue is verified and assessed.
- Once a fix is developed and tested, it will be committed to `main` with coordinated disclosure.
